\section{Descripción del dataset}

Los datos utilizados en este estudio provienen de la base de
\textbf{Estadísticas de Comercio Exterior -- Exportaciones}, publicada
por la Dirección de Impuestos y Aduanas Nacionales (DIAN), validada y
certificada por el Departamento Administrativo Nacional de Estadística
(DANE). Corresponde al mes de junio de 2026 y fue descargada el 12 de
agosto de 2026 desde
\url{https://www.dian.gov.co/dian/cifras/Paginas/EstadisticasComEx.aspx}.

El archivo original contiene 103.179 registros y 72 variables, tal como
se resume en la Tabla~\ref{tab:resumen_original}.

\input{anexos/tabla_resumen_original}

% TODO: párrafo explicando en texto por qué se exploraron las variables
% categóricas antes de seleccionar columnas (ver Tabla categorías).
Para determinar qué variables categóricas eran adecuadas para las
pruebas de hipótesis del proyecto, se exploró el número de categorías
únicas de las variables candidatas (Tabla~\ref{tab:categoricas}).

\input{anexos/tabla_categoricas}

% TODO: párrafo justificando la exclusión de PAIS_DESTINO_FINAL
% (173 categorías) y la selección final de las 11 variables.
Con base en este análisis, se excluyó la variable
\texttt{PAIS\_DESTINO\_FINAL} por presentar 173 categorías únicas, lo
cual la hace inviable para pruebas de hipótesis del tipo chi-cuadrado.
Las variables seleccionadas para el desarrollo del proyecto se
presentan en la Tabla~\ref{tab:variables_seleccionadas}.

\input{anexos/tabla_variables_seleccionadas}

Dado el volumen del dataset filtrado, se optó por trabajar con una
muestra aleatoria simple de 1.500 registros (semilla fija
\texttt{random\_state=42} para garantizar reproducibilidad), con el
fin de evitar sobrecargar el modelo de regresión lineal y reducir los
tiempos de ejecución. La comparación de dimensiones se muestra en la
Tabla~\ref{tab:dimensiones_muestra}.
